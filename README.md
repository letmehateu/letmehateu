# Welcome to My GitHub 👋

Hi there! I'm a smart contract developer and blockchain security researcher passionate about building secure, efficient, and transparent decentralized systems.

## 🔧 What I Do

### **Smart Contract Development**
- I design and implement robust smart contracts using Solidity, following the latest EVM standards and security best practices.
- My focus is on creating code that’s not only functional and scalable but also resistant to common vulnerabilities.

### **Security Research**
- I specialize in identifying and analyzing vulnerabilities in smart contracts and blockchain protocols.
- My work includes discovering exploits, performing audits, and contributing to the continuous improvement of security standards within the Web3 ecosystem.

## 📂 **Projects You’ll Find Here**

- ERC Standards: Implementations and extensions of Ethereum standards such as ERC-20, ERC-721, and ERC-4337.

- Security Tools: Utilities and frameworks for testing and analyzing smart contract vulnerabilities.

- Open Source Contributions: Improvements, bug fixes, and research-driven enhancements for blockchain frameworks and libraries.
